# Лофи-города

Лофи-радио с живым окном в город: **[lofi-goroda.ru](https://lofi-goroda.ru)**.

Пятнадцать городов России — от Санкт-Петербурга до Владивостока. В каждом — пиксельная панорама из окна уютной комнаты, настоящее время и погода, своя уличная жизнь и скрытые секреты, которые можно найти: тигр на сопке, северное сияние, мальчик Онфим с берестой.

## Как это устроено

- **Сцена** — Canvas 2D, 480×270, нарисована кодом без картинок. Небо считается по высоте Солнца (белые ночи и полярная ночь получаются сами), отражения в воде — построчным копированием буфера, погода — Open-Meteo.
- **Эфир** синхронный без стриминга: все слушатели считают позицию трека по часам. Между mp3-треками браузер сочиняет живые вставки на Web Audio.
- **Звуки города** (чайки, трамвай, куранты, прибой) синтезируются в браузере и следуют за погодой и временем.
- **Движок и города** разделены: `site/engine/` — общий движок, `site/cities/<id>/` — модуль города (панорама, места, звуки, секреты).
- **Живой слой** — `server/live.py`: «сколько слушают сейчас», реакции и форма отзывов на asyncio без зависимостей.

## Запуск локально

```bash
python tools/devserver.py 8765
```

Откройте http://127.0.0.1:8765/ — или `/kazan/`, `/murmansk/` и т. д. Полезные параметры адреса: `?t=22:30&d=2026-01-15` (машина времени), `?freeze` (стоп-кадр), `?obs` (без интерфейса), `?secret=<id>` (показать секрет).

Тесты: `python tests/test_live.py` (сервер) и в консоли страницы `const m = await import('/tests/ui_test.js'); await m.run()`.

## Музыка

Треки сгенерированы нейросетью [ACE-Step 1.5](https://github.com/ace-step/ACE-Step) (MIT) по промптам из `tools/music/prompts.json`; сами mp3 в репозиторий не входят. Как сгенерировать — `tools/music/README.md`.
