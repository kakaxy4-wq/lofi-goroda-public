# Бот @oknodnya_bot

Ведёт канал @oknodnya и принимает отзывы. План и решения — `docs/plans/bot.md`.

## Что делает
- **Окно дня.** Каждый день в `POST_TIME` (21:00 МСК) выбирает город по кругу (без повтора 14 дней), снимает кадр
  `{SITE_URL}/<id>/?obs` через Chromium и присылает владельцу черновик. Режим `auto` публикует сразу.
- **Тихие новости.** `/news` собирает разделы `docs/CHANGES.md` новее последней публикации.
- **Отзывы.** Текст от любого, кроме владельца, уходит в `live.py` (`/feedback`, заголовок `X-Bot-Key`),
  копия — владельцу; ответ владельца реплаем возвращается автору. Лимит 5 в час на человека.

## Команды
Для всех: `/start`. Для владельца: `/frame <город|id> [ЧЧ:ММ]`, `/news`, `/mode draft|auto`, `/status`.
Кнопки черновика: В канал · Другой город · Свой текст · Пропустить.

## Окружение
Секреты — только в `/opt/lofi-goroda/bot.env` на сервере (шаблон: `env.example`), в репозиторий не класть.
Данные (SQLite, черновики) — том `lofi-bot-data` (`/data`).

## Выкатка
`bash deploy/deploy.sh` копирует `bot/` и `docs/CHANGES.md` на сервер и делает `docker compose up -d --build`.
`bot.env` создаётся руками один раз. Запускать ровно один экземпляр с этим токеном (иначе 409),
локально на боевом токене бота не запускать.

## Тесты
`py -3 -m pytest tests/test_bot_content.py -q` — логика `content.py` (без Telegram и браузера).
