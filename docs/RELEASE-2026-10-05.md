## Критерии приёмки

### P0 — блокирует рекламу

**Безопасность**

- [ ] **S1. TLS и HSTS.** `curl -sI http://lofi-goroda.ru/` → 301/308 на https; `curl -sI https://www.lofi-goroda.ru/x` → 301 на `https://lofi-goroda.ru/x`; `curl -sI $D/` содержит `Strict-Transport-Security: max-age=` ≥ 15552000; сертификат действителен > 30 дней (`openssl s_client … | openssl x509 -noout -enddate`); `-tls1_1` не устанавливает соединение.
- [ ] **S2. Заголовки на HTML, JS, JSON, mp3.** `for p in / /piter/ /engine/app.js /cities/piter/music/playlist.json; do curl -sI $D$p; done` — в каждом `X-Content-Type-Options: nosniff`, `Referrer-Policy`, CSP с `frame-ancestors 'self'`. На HTML CSP включает `default-src 'self'`, `connect-src 'self' wss://lofi-goroda.ru https://api.open-meteo.com`, `object-src 'none'`, `base-uri 'self'`; живой путь G5 без CSP-ошибок в консоли.
- [ ] **S3. Origin у WebSocket и отзывов.** WS-апгрейд на `$D/live` с `Origin: https://evil.example` → 403, с `Origin: https://lofi-goroda.ru` → 101. `curl -si -X POST -H 'Origin: https://evil.example' -H 'Content-Type: text/plain' --data '{"text":"x x"}' $D/live/feedback` → 403.
- [ ] **S4. Лимиты отзывов.** 7-й POST подряд с одного IP → 429; тело 17000 байт → 413; `[]` и `not json` → 400; текст > 1000 символов обрезается (`py -3 -m pytest tests/test_live.py` зелёный).
- [ ] **S5. XSS через отзыв.** Отзыв `{"text":"<img src=x onerror=alert(1)>","contact":"<script>alert(2)</script>"}` в беклоге личный беклог владельца показан текстом, alert нет. `grep -nE 'innerHTML.*\$\{m\.' site/engine/*.js` — подстановки данных с сервера только чисел (сервер шлёт int).
- [ ] **S6. На проде нет лишнего.** `for p in /.git/HEAD /docs/STATE.md /tests/test_live.py /server/live.py /deploy/deploy.sh /.env /feedback.json /live-data.json /music/raw/; do curl -s -o /dev/null -w "%{http_code} %{size_download} $p\n" $D$p; done` — ни одного 200 с содержимым файла. `ssh myvps2 'ls -a /opt/lofi-goroda/site'` без `.git`, `docs`, `tests`, `*.md`, `*.py`.
- [ ] **S7. Секретов нет.** `git log -p --all | grep -iE "(api[_-]?key|token|secret|password|BEGIN .*PRIVATE)"` пусто; `ssh myvps2 'grep -rIiE "token|secret|api[_-]?key" /opt/lofi-goroda/site | head'` пусто.
- [ ] **S8. Наплыв.** 2000 запросов, 100 параллельно на `$D/piter/` → 0 ответов 5xx; 100 WS-подключений держатся 60 с; `docker stats` live < 128m, web < 64m; `docker inspect -f '{{.State.OOMKilled}} {{.RestartCount}}'` → `false 0`.

**Юридическое РФ**

- [ ] **L1. Политика ПДн (152-ФЗ ст. 18.1).** `$D/privacy/` → 200; называет оператора и способ связи, данные (текст отзыва, контакт, IP в логах, localStorage), цели, срок хранения, удаление по запросу, обращение браузера к Open-Meteo. Ссылка рядом с формой (`grep -n 'privacy' site/engine/app.js`).
- [ ] **L2. Согласие у формы.** Рядом с полем контакта — «Отправляя контакт, вы соглашаетесь с политикой» со ссылкой (`grep -nE 'согла' site/engine/app.js`). Решение по уведомлению РКН (ст. 22) записано в «Известных ограничениях».
- [ ] **L3. Хранение в РФ.** `whois 89.23.102.185 | grep -i country` → RU; отзывы только на этом VPS.
- [ ] **L4. Права на музыку.** Для 2 треков Suno есть подтверждение платного плана на дату генерации (`docs/licenses/`), иначе треки убраны (плейлист без `moros|razveli`, mp3 → 404). Текст «О проекте» не утверждает ложного: упомянут ACE-Step 1.5 (MIT).
- [ ] **L5. Маркировка рекламы (38-ФЗ ст. 18.1).** Для каждого ОПЛАЧЕННОГО поста — erid от ОРД и пометка «Реклама. Рекламодатель …, erid: …». Бесплатные/взаимные посты записаны как таковые.
