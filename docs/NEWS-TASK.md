# Ежедневная задача: тёплые новости → события в сцене

Выполняет Claude по расписанию (раз в день, утром). Владелец не вмешивается.

## Что искать
Приятные, добрые городские события **на сегодня и ближайшие 3 дня** в Петербурге и Казани:
праздники и салюты, фестивали, регаты, «Алые паруса», развод мостов под музыку, световые шоу,
прыжки парашютистов/бейсджамперов с разрешения, запуск фонтанов, открытие навигации,
выставки, день города, спортивные праздники без политики, редкие животные в городе.

## Где искать — только официальные источники
- Петербург: gov.spb.ru, kultura.gov.spb.ru, spbmuseum.ru (Петропавловская крепость), hermitagemuseum.org,
  mostotrest-spb.ru (мосты), visit-petersburg.ru, официальные сайты организаторов.
- Казань: kzn.ru (мэрия), tatarstan.ru, mincult.tatarstan.ru, kazan-kremlin.ru, visit-tatarstan.com.
- Анонсы федеральных/региональных госСМИ допустимы, если ссылаются на организатора.

## Чего нельзя
Политика, происшествия, конфликты, трагедии, скандалы, реклама. Слухи и соцсети без официального
подтверждения. Выдумывать событие или дату. Сомнительно — не добавлять.

## Как добавить
Файл `site/cities/<piter|kazan>/data/events.json`, массив записей:

```json
{ "id": "piter-2026-10-04-basejump", "kind": "basejump", "date": "2026-10-04", "from": "12:00", "to": "15:00",
  "title": "Прыжки со шпиля", "text": "Сегодня с Петропавловки прыгают бейсджамперы — смотрите на шпиль.",
  "source": "spbmuseum.ru", "url": "https://..." }
```

- `kind`: `basejump` (Петропавловка), `fireworks` (салют над крепостью/Кремлём) — рисуются в кадре;
  любое другое значение (например `news`) — только реплика ведущего.
- Время — местное. Старые события (дата < сегодня − 7 дней) удалять.
- После правки: `python tools/devserver.py` не нужен; достаточно `python -m json.tool` для проверки,
  затем `bash deploy/deploy.sh`, коммит и пуш.
- В беклог (личный беклог владельца, проект «Лофи-города») — карточка «Новость: …» и сразу
  `move` в done. Если ничего подходящего — ничего не менять.
