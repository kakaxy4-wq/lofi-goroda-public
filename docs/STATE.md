# Лофи-города — состояние проекта

Обновлено: 2026-09-27

## Что это

Русский ответ loficities.com: живые окна в города России с лофи-эфиром.
Первый город — Петербург. Домен — **lofi-goroda.ru** (Timeweb, A → 89.23.102.185).

## Что уже работает (прототип, `site/`)

- **Сцена** (`js/scene.js`): 480×270 пиксель-арт кодом, без картинок. Нева, Петропавловский
  собор со шпилем и ангелом, Дворцовый мост (разводится по графику), Стрелка с Биржей и
  Ростральными колоннами, Лахта, телебашня, Соборная мечеть, Троицкий мост.
  Интерьер: стол у окна, зелёная лампа, проигрыватель (пластинка крутится, когда играет эфир),
  чай в подстаканнике, книги, кот Елисей, кресло-качалка с пледом, гирлянда, герань и
  сувенирный Чижик на подоконнике.
- **Настоящее время и погода**: Солнце/Луна по астрономии (белые ночи получаются сами),
  погода Open-Meteo, сезоны (осень, зима, лёд на Неве), полуденная пушка, суда во время
  развода, прогулочный теплоход.
- **Эфир** (`js/audio.js`): сетка по unix-времени — все слышат одно и то же.
  Треки Suno (`site/music/playlist.json`) чередуются с генеративными вставками
  (браузер сочиняет лоуфай: аккорды, бас, барабаны, мелодия, «лента»).
- **Звуки города** — отдельный микшер: дождь, Нева, ветер, город, чайки, трамвай,
  куранты Петропавловки (каждые 15 минут, в тональности трека), пушка, гудки, кот, ложечка.
- **Интерактив**: клик по зданиям — карточки с фактами и действиями («Показать разводку»,
  «Показать выстрел», «Зажечь факелы»); мини-игры «Монетка Чижику-Пыжику» и «Монетка Зайцу»;
  кот мурчит, кресло качается, лампа и гирлянда включаются.
- **Интерфейс** в пиксельном стиле (шрифт Pixelify Sans, OFL, лежит в `site/fonts`),
  быстрые кнопки, таймеры фокуса (25/5, 50/10, 90/15) и сна, машина времени,
  автоскрытие интерфейса через 6 с, режим `?obs` для стримов.
- **Живой слой** (`server/live.py` + `site/js/live.js`): «N слушают сейчас · M сегодня»,
  реакции (сердце, нота, звезда, луна) видят все, общий дневной счётчик монеток Чижику и Зайцу.
  Python, только стандартная библиотека; в проде — контейнер `live`, путь `/live` через Traefik.
- **PWA**: манифест, иконки, service worker (офлайн-оболочка; без сети эфир уходит в
  генеративные вставки). Превью для соцсетей — `site/img/og-piter.png`.
- Параметры адреса для проверки: `?t=01:30&d=2026-06-21&wx=rain|snow|fog|storm|clear|cloudy`.

- **Обратная связь**: форма и голосование за город в «О проекте» → `POST /live/feedback` →
  `/root/kanban-board/lofi-goroda/feedback.json` на VPS → проект «Лофи-города» в беклоге
  личный беклог владельца (адрес не публикуется) (источник добавлен в `FEEDBACK_SOURCES` server_backlog.py,
  бэкап рядом). Лимит — 6 отзывов в час с IP (`FB_PER_HOUR`).
- **Контакты** в «О проекте» — константа `CONTACTS` в `site/js/main.js`, пока заглушка.

## Тесты

- `python tests/test_live.py` — 31 проверка протокола, 6 независимых пользователей, свой сервер на :8799.
- `tests/ui_test.js` — 31 проверка интерфейса; прогнано на 7 экранах (375×812, 360×640, 844×390,
  768×1024, 1536×730, 1920×969, 2560×1080) — всё зелёное. Запуск: статика из корня репозитория,
  открыть `/site/`, в консоли `(await import('/tests/ui_test.js')).run()` при запущенном `server/live.py`
  с `FB_PER_HOUR=100`.

## Устройство (движок + города)

- `site/engine/` — общее: `app.js` (интерфейс, время, эфир, панели), `scene.js` (небо, вода, погода,
  интерьер, кот), `audio.js` (эфир и звуки), `weather.js`, `astro.js`, `games.js`, `live.js`, `boot.js`.
- `site/cities/<id>/index.js` — модуль города: `config`, `skyline` (палитры, силуэт, свои слои),
  `sounds` (список, события), `env`, `ticker`, `places`, игры, тексты. `cities/index.json` — реестр.
- Адреса: `/piter/`, `/kazan/`; страницы генерирует `tools/build_pages.py` (вызывается в deploy.sh).
- Визуальная регрессия: `tests/visual_capture.html` + `tests/visual_compare.py` (8 стоп-кадров,
  попиксельно). Переделка движка прошла без единого отличающегося пикселя.

## Как запустить локально

```
python tools/devserver.py 8765     # сайт с корня, тесты по /tests/
python server/live.py          # счётчик и реакции на :8766, сайт сам подключится с localhost
```

## Выкладка

`bash deploy/deploy.sh` — заливает `site/` в `/opt/lofi-goroda/site` на VPS (ssh-хост `myvps2`),
кладёт `docker-compose.yml` и `nginx.conf`, пересоздаёт контейнер. Traefik общий
(`matrix-traefik`, сеть `traefik`, certresolver `default`), www → редирект на корень.

**Статус: выложено 27.09.2026**, https://lofi-goroda.ru работает (HTTPS, www → корень, /live — счётчик).

DNS: на 17:30 27.09 домен ещё не появился в зоне .ru (регистрация свежая). После появления
Traefik сам выпустит сертификат Let's Encrypt; если первый выпуск не удался — пересоздать
контейнер (`docker compose up -d --force-recreate web`).

## Казань (второй город)

`site/cities/kazan/`: вид с северного берега Казанки на Кремль (Кул-Шариф, Благовещенский собор,
Сююмбике, Спасская башня, дворец, мост Миллениум, Кремлёвская дамба), ночная подсветка, лёд на
Казанке с декабря по начало апреля, теплоходы в навигацию, стрижи летними вечерами, бой часов.
Звук без имитации азана и колоколов. Треков пока нет — играют живые вставки (плейлист пустой).

## Музыка: набор ACE-Step

`tools/music/` — 60 промптов (36 Питер, 24 Казань), `generate.py` для GPU-сервера,
`make_playlist.py`, инструкция `README.md`. Нужен почасовой GPU на 24 ГБ (A5000), ~1–2 ч.

## Продвижение

План на 14 дней и разбор запуска loficities — `docs/PROMO.md`.

## Решения

- Музыка — формат «радио», а не плеер: общая сетка по часам, без стриминга (сервер отдаёт файлы).
- Генеративные вставки нужны, пока треков мало (сейчас 2), позже — как офлайн-режим.
- Код и графику loficities не копируем, всё своё.
- Весь звук города синтезируется, файлов нет.
