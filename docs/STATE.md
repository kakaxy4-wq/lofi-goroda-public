### Грабли этого проекта
- Длинная сессия = дорого: при контексте 650k каждое действие перечитывает весь разговор → начинать новую сессию с этого файла.
- `pkill -f "<текст>"` внутри ssh-команды убивает и саму ssh-сессию (совпадает текст команды) → запускать отдельно или через скрипт-файл без этого текста.
- Скрытая панель браузера: rAF стоит, анимации не идут; тесты — `?freeze` и снимки через `scratchpad/recv.py` (порт 8838).

- GPU-аренды: реальная цена ~70–115 ₽/ч; mp3 делать не на сервере (`--no-post`); FLUX закрыт — SDXL; итоги в docs/GPU-QUEUE.md.
